# Projeto-Restaurante-emJava

As funcionalidades deste projeto são:
- Gerenciar cardápio: Adicionar, Alterar, Listar e Remover pratos e bebidas;
- Abrir Pedido: Criar um novo pedido para cada mesa e adicionar itens a ele;
- Calcular conta: Somar o valor total de todos os produtos do pedido do cliente;
- Pagamento: Registrar desconto para estudantes
