# Projeto-Restaurante-emJava
README – Sistema de Gerenciamento de Restaurante

Descrição

Este projeto é um sistema de gerenciamento de restaurante desenvolvido em Java, na disciplina de POO ministrada pelo professor Leonardo Lucena. O sistema permite administrar o cardápio, realizar pedidos por mesa, calcular o valor da conta e aplicar desconto para estudantes no momento do pagamento.
____________________________________________________________________________________
## Como executar

1. Abra o projeto.
2. Compile o projeto.
3. Execute o arquivo Main.
4. Utilize o menu exibido no terminal para acessar as funcionalidades do sistema.
____________________________________________________________________________________
## Funcionalidades

### Gerenciar Cardápio

Permite realizar o gerenciamento completo dos pratos e bebidas disponíveis no restaurante.

* Adicionar pratos e bebidas;
* Alterar informações de itens existentes;
* Listar todos os produtos cadastrados;
* Remover pratos ou bebidas do cardápio;

### Abrir Pedido

Permite criar um pedido para uma mesa e adicionar os itens desejados.

* Criar um novo pedido;
* Associar o pedido a uma mesa;
* Adicionar produtos do cardápio ao pedido.

### Calcular Conta

Calcula automaticamente o valor total do pedido realizado pelo cliente, considerando todos os itens adicionados.

### Pagamento

No momento do pagamento, o sistema permite aplicar desconto para clientes estudantes, atualizando automaticamente o valor final da conta, caso você não tenha dinheiro suficiente, você irá lavar pratos o dia todo!
